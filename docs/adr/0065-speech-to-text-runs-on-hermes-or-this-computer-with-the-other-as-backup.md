# Speech to text runs on Hermes or on this computer, with the other as backup

Issue #192 asks to pick where Dictation and voice conversations (ADR 0111) turn speech into text: on the Hermes server, as before, or on the computer running Hermes Chat, or both, with one as the automatic backup for the other. On this computer the owner picks a Whisper model size and language, sees its size and whether it is downloaded, downloads or deletes it, sees where it is kept, or points at a model file they already have. A Test records a few seconds and shows what each option heard and how long it took.

ADR 0067 (#220, the first slice of #192) already lets this computer transcribe with an engine already installed here, and has Rust alone decide where a recording goes. This ADR builds on it: everything 0067 decides still holds, and where this one adds to a decision, it says so.

## Decisions

- **Where it runs, and the backup, are kept and decided by Rust.** `local-stt.json` (ADR 0067) gains `backup`, `timeoutSeconds` (5 to 600, 30 by default) and `language`. A file from before reads as no backup, 30 s and `auto`; a value out of range is brought into it, but a file that doesn't parse is still an error, never "Hermes". `local_stt_set` takes a change of any of them and refuses it whole if any part is out of range or names an engine or model that wasn't found.
- **One route, inside `hermes_transcribe`** (`local_stt::route`). The primary runs; if it fails (Hermes not connected or unreachable, a provider error, no engine or model here, the engine failing) or, with a backup, takes longer than the time set, the backup runs on the same recording. Neither side starts unless it is tried: with This computer and no backup, Hermes's request is never even built, so ADR 0067's guarantee holds. An empty transcript is an answer, not a failure: the owner said nothing. A late answer from a timed-out primary is dropped. The primary is timed only when a backup is waiting; otherwise it gets as long as it takes (this computer stops itself after ADR 0067's limit).
- **What the answer says.** It names the side that ran (`ran`) and, when the backup gave the text, why the primary didn't (`fellBack`). Dictation shows that as a note (a status, not an alert), and a voice conversation's "What Hermes got" shows it under the turn: "Transcribed on this computer. Hermes couldn't transcribe it: …". When both fail, the error says what each said, and Dictation keeps the recording to try again, as before. Hermes alone fails with its own error, unchanged; this computer alone as "This computer couldn't transcribe it: …".
- **Cancelling stops the backup too.** Each transcription carries a run id (`x-stt-run`). Cancel, closing the chat, or ending or pausing a conversation sends `local_stt_cancel` with it: what runs is dropped (a local engine is killed) and the backup isn't tried. A cancel that arrives before its transcription is kept a minute, so the order the two commands arrive in doesn't matter.
- **Whisper models for whisper.cpp are downloaded and checked.** `https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-<size>.bin` for tiny, base, small, medium and large-v3, with each size's exact byte count and SHA-256 pinned from the repository's LFS listing (read 2026-11-04). A download streams into a hidden `.part` file in `<app data>/whisper-models`, is cut off past the size or after 60 s with nothing, and is renamed into place only when the size and checksum match; anything else is deleted. One runs at a time and can be cancelled. That folder is one of whisper.cpp's model folders that ADR 0067's detection reads, so a downloaded size is chosen like any model found: Use sets it as whisper.cpp's model, checked by `local_stt_set` against a fresh scan. Delete removes only those five files, never a model found elsewhere or picked in a dialog.
- **Language.** `auto` or a Whisper code (two or three lowercase letters). whisper.cpp gets `-l <code>`; faster-whisper and OpenAI Whisper get `--language <code>` unless it is `auto`; Vosk's language is its model's.
- **The webview knows the route without Hermes.** Main reads the route from Rust at start and after each change, into a small store (`sttRoute`). With this computer in the route, first or as backup, the microphone isn't blocked while Hermes is disconnected, and a voice conversation doesn't need Hermes's own speech to text; if this computer can't run either, the answer says why. A voice conversation still needs Hermes, which it sends each turn to.
- **Settings → Voice → Speech to text is one section**: Where it runs and Backup (radio groups), the time before the backup, the profile's provider on Hermes (picked under Speech providers, ADR 0115; no second picker), and, once this computer is in the route, ADR 0067's engine and model with the language and the five Whisper sizes. A primary on this computer that can't run says what happens instead: the backup, or nothing sent to Hermes.
- **Test** records five seconds once, then has each side that may get a recording transcribe it alone (`x-stt-side`), the primary first, and shows the text, the time and the engine or provider, or why it failed. Rust refuses `x-stt-side: server` when this computer is alone, so the Test can't send it to Hermes either; it says so instead. This computer is tried even when it isn't in the route, and while Hermes is offline.

## Considered options

- **Route in the webview, with a separate `local_stt_transcribe` command.** This branch's first version did; rejected when #220 landed. ADR 0067 rejects it for the reason that still holds: a webview bug could send a recording to Hermes that the owner kept here.
- **Keep Primary, Backup and the timeout in the webview's display preferences.** Rejected for the same reason: Rust must know them to decide.
- **Only "This computer" can be the primary once a model is there.** This branch's first version disabled it until then; ADR 0067 lets the owner pick This computer first and choose the engine after, and says what's missing meanwhile. ADR 0067's way is kept: the section says plainly that nothing goes to Hermes until it can run, or that the backup does.
- **whisper-rs (whisper.cpp linked into the app).** Rejected for now. It needs cmake and a C++ toolchain at build time, adds a large native build to every `cargo build`, and pins a whisper.cpp version to the app's releases. Running the program the owner installed keeps the app small and lets the owner choose a GPU build.
- **Downloads for faster-whisper, OpenAI Whisper and Vosk.** Not now: each has its own model cache and format, so "see its size, download or delete it" can't be done the same way. Their models are still found and used (ADR 0067).
- **Time the primary even with no backup.** Rejected: with nothing to switch to, a timeout only throws away a slow but good transcript.

## Consequences

- An owner can dictate with no audio leaving the computer, offline too, and have Hermes catch the cases the local engine can't (or the other way round), seeing which one did it. Choosing Hermes as the backup is choosing that a recording can leave this computer when this computer fails; Settings says so.
- The pinned checksums follow whisper.cpp's repository as of 2026-11-04. If it replaces a file, the download is refused as not matching until the pins are updated.
- Verified with a real whisper.cpp v1.9.5 built on the build box and the real `tiny` model through the merged code (`real_whisper_cpp`, run with `HERMES_TEST_WHISPER_*` set). The route, timeouts, cancel and downloads are unit-tested in Rust against stand-in engines and a loopback server; the webview's notes and Settings against a stand-in that follows the same rules (`fakeLocalStt.ts`).
